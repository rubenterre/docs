UTILIZACIÓN DE ETIQUETAS

As etiquetas ou marcas en HTML son códigos especiais que se utilizan para definir a estrutura, o contido e a aparencia dos documentos na web.

• As etiquetas de HTML definen cabeceiras, parágrafos, listas, imaxes…

• Os atributos de HTML son información adicional que se engade dentro das etiquetas para especificar características do elemento.

ETIQUETAS
ATRIBUTOS

Etiquetas

• Etiquetas de HTML de inicio e peche:

<p> Exemplo de párrafo </p> <h1>Exemplo de titular </h1>

• Etiquetas de HTML sen peche (autopeche):

<img src="imaxe.jpg" alt="imaxe de exemplo"/> <br> <hr>

ATRIBUTOS

Exemplo:

<img src="imaxe.jpg" alt="imaxe de exemplo"/>

Neste exemplo tanto src="imaxe.jpg" como a alt="imaxe de exemplo" son atributos da etiqueta de imaxe xa que engaden datos que definen unha imaxe nunha ubicación e un texto alternativo.

COMPATIBILIDADE

Cada vez menos, pero dependendo do navegador existen etiquetas que varían na súa sintaxe. Como a etiqueta <bgsound> que era exclusiva Internet Explorer.

• Comprobar a compatibilidade dunha etiqueta:
https://caniuse.com/

• Comprobar se o noso código é estandarizado, é dicir, validado pola W3C:
https://html.spec.whatwg.org/

Atópanse dentro do <head> dunha páxina web

<!DOCTYPE html>
Especifica a versión do HTML

A máis usada é esta que corresponde a HTML5

<html>
Indica o inicio do documento HTML

É a etiqueta que marca o inicio e o fin do documento HTML

<head>
Contén a información sobre o documento

Encontramos o título, descrición, palabras chave…

<meta charset="UTF-8">
Especifica a codificación de caracteres

UTF-8 é unha codificación versátil capaz de representar practicamente calquera caracter de todas as linguas, así como símbolos e emojis.

<title>
Define o título da páxina

Aparece na lapela do navegador e nos resultados de busca.
