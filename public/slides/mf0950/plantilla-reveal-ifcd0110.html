Cómo usar esta plantilla

1. Duplica el HTML

Parte de este archivo y renómbralo según módulo, unidad y número de presentación, por ejemplo uf1287-01.html.

2. Mantén el tema común

La identidad visual vive en /slides/reveal-theme-ifcd0110.css, así todas las presentaciones comparten base.

3. Cambia solo el contenido

Reemplaza título, secciones, tablas y bloques. Reveal.js ya te da navegación, progreso y modo speaker.

4. Enlaza desde docs

En cada archivo Markdown usa rutas como /slides/mf0950/uf1287-01.html.

Componentes

Bloques visuales disponibles

Hero Portada con composición visual y claim corto.
Cards Cuadrículas de 2 o 3 bloques para conceptos, pasos o recursos.
Code Bloques de código con Fira Code, borde fino y fondo oscuro integrado.
El objetivo no es hacer slides espectaculares por efecto, sino presentaciones limpias, legibles y consistentes con la documentación del temario.
